# homebrew-codex-shake

Homebrew tap for `codex-shake`, the `eric/local-features` fork build of the Codex CLI
from https://github.com/epsalmond/codex. It installs as `codex-shake` beside an
official `codex` install.

```sh
brew install epsalmond/codex-shake/codex-shake
brew upgrade epsalmond/codex-shake/codex-shake
```

macOS arm64 and Linux x86_64 only. `Formula/codex-shake.rb` is generated by the
fork's release workflow (`.github/workflows/fork-release.yml`, "Update Homebrew tap")
on every published release; do not hand-edit it.
